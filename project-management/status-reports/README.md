# Project Status Reports

This folder contains periodic project status reports for the Employee Management System.

Each report should document:

- Overall project status
- Work completed during the reporting period
- Work currently in progress
- Upcoming activities
- Schedule and scope updates
- Risks and issues
- Decisions and action items

## Naming Convention

Use the following format:

`project-status-week-01.md`  
`project-status-week-02.md`  
`project-status-week-03.md`

Reports will be added as the project progresses.
