# Sprint Reports

This folder contains sprint reports for the Employee Management System.

Each report should summarize:

- Sprint goal and dates
- Planned backlog items
- Completed work
- Incomplete work
- Testing results
- Issues and blockers
- Stakeholder feedback
- Lessons learned

## Naming Convention

Use the following format:

`sprint-01-report.md`  
`sprint-02-report.md`  
`sprint-03-report.md`

Reports will be added after each sprint is completed.
