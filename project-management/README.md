# Wrio Byte – Project Management

This folder contains the project management documents used to plan, organize, monitor, and track the development of the Wrio Byte Employee Management System.

## Contents

| File / Folder | Purpose |
|---|---|
| `product-backlog.md` | Lists and prioritizes product features and development requirements |
| `sprint-planning.md` | Records sprint goals, selected backlog items, and planned work |
| `sprint-reports/` | Stores sprint progress and review reports |
| `status-reports/` | Stores overall project status updates |

## Project Management Approach

**Methodology:** Agile / Scrum  
**Project Duration:** 8 weeks (initial estimate)  
**Task Management:** Trello  
**Source Control and Documentation:** GitHub

The documents will be updated as requirements are validated, the development team is assembled, and sprint activities are completed.
